# 🌸 BeyondHana

**BeyondHana** คือเกม Visual Novel ที่พัฒนาด้วย .NET MAUI เพื่อให้ทุกคนได้สัมผัสประสบการณ์การอ่านเนื้อเรื่องและเลือกเส้นทางชีวิตผ่านโลกนิยายภาพ

โปรเจกต์นี้เกิดจากความตั้งใจของทีมงานเล็ก ๆ ที่อยากสร้างสรรค์เกมเนื้อเรื่องภาษาไทยสำหรับคนไทย โดยเน้นประสบการณ์เล่นที่เข้าถึงง่าย ภาพสวย และเนื้อเรื่องที่ชวนติดตาม

---

## 💡 เกี่ยวกับโปรเจกต์

- 🚀 สร้างด้วย **.NET MAUI** (บน .NET 9) ทำให้ตัวเกมมีศักยภาพในการพัฒนาให้สามารถเล่นได้หลายแพลตฟอร์ม แต่ปัจจุบันผู้พัฒนาได้เผยแพร่ (deploy) ตัวเกมสำหรับระบบปฏิบัติการ **Android** เป็นหลัก
- 🌐 **อินเตอร์เฟสของเกมเป็นภาษาอังกฤษ** แต่ **เนื้อเรื่องทั้งหมดเป็นภาษาไทย**
- 📖 ตัวเกมนำเสนอเรื่องราวผ่านภาพและข้อความ พร้อมระบบตัวเลือกที่นำไปสู่ตอนจบที่แตกต่างกัน

## 🛠️ วิธีเริ่มต้น

1. ดาวน์โหลดและติดตั้ง [.NET 9 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0) หรือใหม่กว่า
2. ติดตั้ง MAUI workload ด้วยคำสั่ง
    ```
    dotnet workload install maui
    ```
3. โคลนโปรเจกต์นี้
    ```
    git clone https://github.com/etsuwithtea/BeyondHana.git
    ```
4. เปิดโปรเจกต์ด้วย Visual Studio 2022 หรือใหม่กว่า (ที่รองรับ .NET MAUI และ .NET 9)
5. สั่งรันโปรเจกต์ โดยแนะนำให้เลือกแพลตฟอร์ม Android
