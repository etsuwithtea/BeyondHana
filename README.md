# 🌸 BeyondHana

**BeyondHana** คือเกม Visual Novel ที่พัฒนาด้วย .NET MAUI เพื่อให้ทุกคนได้สัมผัสประสบการณ์การเล่าเรื่องแบบอินเตอร์แอคทีฟผ่านภาษาไทย พร้อมอินเตอร์เฟสภาษาอังกฤษ

**BeyondHana** is a Visual Novel game developed with .NET MAUI, offering an interactive storytelling experience in Thai, with an English interface for international accessibility.

โปรเจกต์นี้เกิดจากความตั้งใจของทีมงานเล็ก ๆ ที่อยากสร้างสรรค์เกมเนื้อเรื่องภาษาไทยที่เข้าถึงได้ง่ายบนแพลตฟอร์มสมัยใหม่

This project was created by a small team aiming to craft a Thai-language story-driven game that is easily accessible on modern platforms.

---

## 💡 เกี่ยวกับโปรเจกต์ | About the Project

- 🚀 สร้างด้วย **.NET MAUI** (บน .NET 9) ทำให้ตัวเกมมีศักยภาพในการพัฒนาให้สามารถเล่นได้บนหลายระบบปฏิบัติการ (ขณะนี้รองรับ Android)
- 🚀 Built with **.NET MAUI** (on .NET 9); the game is structured for potential cross-platform deployment (currently Android supported).

- 🌐 **อินเตอร์เฟสของเกมเป็นภาษาอังกฤษ** แต่ **เนื้อเรื่องทั้งหมดเป็นภาษาไทย**
- 🌐 **Game interface is in English** but **all story content is in Thai**.

- 📖 ตัวเกมนำเสนอเรื่องราวผ่านภาพและข้อความ พร้อมระบบตัวเลือกที่นำไปสู่เส้นทางเนื้อเรื่องที่แตกต่างกัน
- 📖 Story is delivered through visuals and text, featuring a choice system that leads to branching paths and multiple endings.

## ✨ ฟีเจอร์เด่น | Key Features

- 📝 อินเตอร์เฟสเป็นภาษาอังกฤษ เพื่อความเข้าใจง่ายสำหรับกลุ่มผู้เล่นนานาชาติ
- 📝 English interface for international ease-of-use

- 🇹🇭 เนื้อเรื่องและบทสนทนาในเกมเป็นภาษาไทยทั้งหมด
- 🇹🇭 Full story and dialogue in Thai

- 🔀 ระบบตัวเลือก (Choice) ที่ส่งผลต่อเนื้อเรื่องและตอนจบ
- 🔀 Choice system affecting story progression and endings

- 🖼️ ภาพประกอบและ UI ที่ออกแบบมาเพื่อประสบการณ์ Visual Novel
- 🖼️ Custom illustrations and UI for an immersive visual novel experience

- 📱 ศักยภาพในการขยายไปสู่หลายแพลตฟอร์ม แต่ปัจจุบันเปิดให้เล่นบน Android
- 📱 Potential for cross-platform deployment, currently available on Android

## 🛠️ วิธีเริ่มต้น | Getting Started

1. ดาวน์โหลดและติดตั้ง [.NET 9 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0) หรือใหม่กว่า  
   Download and install [.NET 9 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/9.0) or later

2. ติดตั้ง MAUI workload ด้วยคำสั่ง  
   Install MAUI workload:
   ```
   dotnet workload install maui
   ```

3. โคลนโปรเจกต์นี้  
   Clone the repository:
   ```
   git clone https://github.com/etsuwithtea/BeyondHana.git
   ```

4. เปิดโปรเจกต์ด้วย Visual Studio 2022 หรือใหม่กว่า (ที่รองรับ .NET MAUI และ .NET 9)  
   Open the project in Visual Studio 2022 or newer (with .NET MAUI and .NET 9 support)

5. สั่งรันโปรเจกต์ โดยแนะนำให้เลือกแพลตฟอร์ม Android  
   Run the project, preferably targeting Android
